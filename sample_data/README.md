# 示範資料

可在「資料管理 → 批次匯入」上傳下列檔案，或使用 `POST /api/v1/record-imports` 的 multipart `file` 欄位。

| 檔案 | 用途 |
|---|---|
| [records.json](records.json) | 2 筆溫度資料，驗證 JSON 陣列匯入 |
| [records.csv](records.csv) | 4 筆跨日期、跨分類資料，驗證匯入與分析 |
| [records-invalid.csv](records-invalid.csv) | 第 3 列數值錯誤、第 4 列設備不存在、第 5 列時間缺少時區，驗證整批不寫入及錯誤列號（含標題列） |

需要 User 或 Admin；記錄擁有者為目前登入者，這些檔案不會由系統自動匯入。

| 匯入方式 | 相同內容再次提交的行為 |
| --- | --- |
| 同一登入 Session 的 Streamlit 介面 | 成功匯入後依檔案內容摘要阻擋重複提交；只換檔名也不會解除限制 |
| 登出後重新登入，再從介面匯入 | 前次 Session 的紀錄已清除，相同內容可新增另一批 |
| 直接呼叫匯入 API | 採新增語意，沒有跨請求去重；相同檔案再次成功提交會新增另一批 |

若請求逾時或網路中斷、無法確認匯入結果，先查詢資料管理再決定是否重試。展示時查詢日期留空，或選涵蓋範例的 2026-11-07／08；詳細規則見 [資料交換規則](../docs/analytics.md#批次匯入)。
