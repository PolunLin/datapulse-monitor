# 第三階段介面規格

以 `monitor-concept.png` 為監控頁參考；採用 Streamlit 原生表單、導覽、表格與 Altair 圖表，所有資料均來自 API，不把示意數字放入正式畫面。

| 項目 | 規格 |
|---|---|
| 色彩 | 白底 `#FFFFFF`、灰側欄 `#F0F3F7`、深色文字 `#122139`、青綠 `#00897B`、異常紅 `#DC3545` |
| 字體 | 原生無襯線；標題 32px、內文 16px、輔助文字 14px；沿用 Streamlit 控制項字型 |
| 導覽 | 左側 DataPulse、原生 `st.page_link` 的即時監控／資料管理；帳號、角色與登出 |
| 監控頁 | 標題、分類／顯示筆數／暫停／清除控制、連線狀態、四個指標、主要折線圖、下方柱狀圖與告警表 |
| 登入頁 | DataPulse 標題、說明、登入／註冊頁籤、email 與密碼表單；無假資料或宣傳圖片 |
| 資料頁 | 資料管理標題、篩選表單、資料表與分頁、建立／詳細編輯表單、刪除確認 |
| 元件 | 原生按鈕／輸入／下拉選單／表格，薄框指標與圖表，避免額外巢狀容器 |
| 響應式 | 以 Streamlit columns 在窄螢幕自然堆疊；側欄可收合，表格可水平捲動；640px 以下增加頂部留白，避免標題與側欄開關重疊 |

允許的監控主畫面文字：DataPulse、即時監控、資料管理、登入者 email、角色、登出、每秒更新的監測資料與異常事件、分類、顯示筆數、暫停接收／繼續接收、清除畫面、連線狀態、最新數值、異常事件、接收筆數、最近更新、數值趨勢、最近數值、異常告警、即時接收不代表已完成入庫，以及實際資料與必要的錯誤／空白狀態說明。

必要差異：圖表軸及提示均顯示 UTC，加入軸標籤及入庫說明；同分類資料間隔超過 10 秒或時間倒退時將趨勢分段，不畫出沒有觀測資料的連續線。不照抄示意圖的隨機數字、數值上限或假帳號。表單與導覽依原生 Streamlit 尺寸呈現，保留鍵盤與螢幕閱讀器操作。

控制項保留規則：監控分類、顯示筆數及資料管理篩選輸入在同一登入 Session 內跨頁保留；暫停也會維持。登出或認證失效時全部清除。暫停時定期驗證登入狀態，驗證暫時失敗則隱藏圖表，驗證恢復後才重新顯示。

概念由內建 Image Gen 產生，提示要求完整繁體中文 Streamlit 即時監控頁、白灰青綠配色、四個指標、折線圖與柱狀圖、紅色告警表，以及原生可實作的導覽和控制項。未使用外部圖片素材。

## 瀏覽器與視覺驗收

內建 Browser/IAB 啟動逾時，改以 Playwright CLI 的 Chromium 實際操作。桌面尺寸與概念同為 1536 × 1024；手機為 390 × 844，實測 body 寬度為 390，沒有水平溢出。使用 `view_image` 直接對照概念與最後實作截圖，並檢視手機主畫面及圖表捲動區。

| 檢查 | 結果／修正 |
|---|---|
| 版面順序 | 品牌與兩頁導覽、控制列、四個指標、主趨勢圖、柱狀圖與告警；將品牌移至導覽之前 |
| 配色 | 保留白底、灰側欄、青綠操作／正常資料與紅色異常，不使用額外影像或漸層 |
| 字級與密度 | 標題 32px、區塊標題 20px；降低圖表高度，使兩個下方區塊在桌面首屏可見 |
| 圖表與資料 | 使用真實事件、UTC 軸與提示、灰閾值線；暫停產生的空白區間不繪製虛構連續趨勢 |
| 控制項與圖示 | 原生 Streamlit 表單、Material 圖示與側欄連結；鍵盤輸入及刪除確認可操作 |
| 手機 | 控制與指標自然堆疊；修正收合側欄按鈕遮住標題，圖表可正常捲動檢視 |
| 文案 | 無額外宣傳文字；保留允許標籤，另加必要 UTC／資料缺口／入庫狀態說明 |

保留的差異是 Streamlit 原生側欄寬度、按鈕尺寸與導覽選取樣式，以及真實資料數量／數值；不模仿概念中的假帳號與示意數字。已依這些原生元件限制驗證設計落地，未留下裁切主要內容或無法操作的控制項。
